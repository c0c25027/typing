# Word Mind Map（英単語マインドマップ）

英単語を1つ置くと、関連語の候補（連想・類義語・対義語・意味が近い語）が出てきます。
候補をクリックするか、**声に出して言う**とマップにつながっていきます。

## 起動方法

マイクを使うため、ローカルサーバー経由で開いてください（`file://` ではマイクが使えない場合があります）。

```bash
cd mindmap
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

推奨ブラウザ：Chrome / Edge（音声入力に対応）。Safari も対応している見込みですが未検証です。

## 使い方

1. 最初の英単語を入力して「追加」、または 🎤 を押して話します（例: *ocean*）。
2. 単語をクリックすると右パネルに意味（英英）と関連語の候補が出ます。
3. 候補をクリック、または候補の単語を 🎤 で話すと、その関連の色の線でつながります。
4. 候補に無い単語も入力・音声で追加できます（灰色の「手動」の線になります）。

| 操作 | 方法 |
|---|---|
| 音声入力の開始／停止 | 🎤 ボタン、または M キー |
| 複数語をまとめて追加 | `sea, wave, fish` のようにカンマ区切り |
| 発音を聞く | 単語をダブルクリック、またはパネルの 🔊 |
| 移動・拡大縮小 | ドラッグ／マウスホイール／＋−ボタン／「全体」 |
| 削除 | 単語を選んで Delete キー、またはパネルの「削除」 |
| 保存 | 自動（ブラウザ内）。「書き出し」で JSON ファイルに保存 |

インターネットに接続できない場合は、内蔵の小さな辞書（約25語）から候補を出します。

設計の詳細は [docs/SYSTEM_OVERVIEW.md](docs/SYSTEM_OVERVIEW.md) を参照してください。
